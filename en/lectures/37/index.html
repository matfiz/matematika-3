Lecture 37

Local equations and critical points

What this lecture does

A nonsingular derivative allows local equations to determine unknown coordinates. We state the precise existence theorems used for that step. Second derivatives then describe how a scalar function differs from its linear approximation. Their quadratic term classifies nondegenerate critical points in two variables.

37.1 Local inversion

The inverse of a linear map exists when its matrix is nonsingular. For a nonlinear map, an invertible derivative gives an inverse in a neighbourhood, rather than necessarily on the whole domain. A neighbourhood here means an open set containing the specified point.

37.3 Mixed second derivatives

A scalar function is C2C^2C2 on an open set when all its partial derivatives through order two exist and are continuous there. Write ∂j∂if\partial_j\partial_i f∂j​∂i​f for differentiation first in coordinate iii and then in coordinate jjj. 37.5 Critical points in two variables

A point aaa of a differentiable scalar function is critical when ∇f(a)=0\nabla f(a)=0∇f(a)=0. A local minimum means that f(x)≥f(a)f(x)\geq f(a)f(x)≥f(a) for all xxx in some ball about aaa; it is strict when the inequality is strict for x≠ax\ne ax=a. Maxima reverse these inequalities. At an interior local extremum, each coordinate restriction has a scalar extremum. Fermat’s theorem makes every partial derivative zero, so the point is critical. A critical point is a saddle point when every ball about it contains points whose values are above f(a)f(a)f(a) and points whose values are below f(a)f(a)f(a).

Summary

  • The inverse theorem requires a C1C^1C1 map on an open domain and a nonsingular square Jacobian. It supplies a local C1C^1C1 inverse [C]. The implicit theorem requires a C1C^1C1 map on an open domain, a specified solution and an invertible dependent-variable block, and supplies a unique local graph [C].
  • Theorem 37.5: continuous second partial derivatives commute, so a C2C^2C2 scalar function has a symmetric Hessian.
  • Theorem 37.6: the quadratic approximation has remainder o(∥h∥2)o(\norm h^2)o(∥h∥2) as h→0h\to0h→0, uniformly over all approaches. It is proved from a scalar Taylor formula on the line segment.
  • Theorem 37.7: at a planar C2C^2C2 critical point, positive Hessian determinant gives a strict minimum or maximum according to the first diagonal sign. A negative determinant gives a saddle; zero is inconclusive.
